## 🔍 Diagnóstico y Causa Raíz Detectada

1. **Problema detectado por el usuario en producción:**
   - La página `https://www.profeonline.cl/aprender/matematicas/geometria/poligonos-y-cuadrilateros/poligonos-conceptos-y-angulos/definicion-de-poligono-como-figura-plana-cerrada-formada-por-segmentos/` mostraba el contenido genérico anterior (con distractores genéricos, sin las infografías nuevas y con la ruta vieja `/static/img/geometria/...`).

2. **Causa Raíz:**
   - Existían **335 archivos YAML legacy duplicados** (antiguos archivos `mat-geo-*.yaml` y `mat-alg-*.yaml` anteriores a la estandarización por slugs).
   - Al ejecutarse el comando de importación `load_node_content`, se leían todos los archivos `*.yaml` en orden alfabético (`sorted(dirpath.glob("*.yaml"))`).
   - Debido a que `mat-*` comienza con la letra `m`, para todos los archivos canónicos con nombres alfabéticos entre la `a` y la `l` (ej. `definicion-de-poligono-...yaml`), el archivo legacy `mat-geo-poligonos-definicion.yaml` se ejecutaba después y sobreescribía (`update_or_create`) el registro de `NodeContent` en la base de datos con el contenido genérico antiguo.
